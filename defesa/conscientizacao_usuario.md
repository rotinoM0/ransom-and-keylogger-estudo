# Conscientização do Usuário em Segurança da Informação

## Sumario

A conscientização do usuário é um dos pilares mais importantes da segurança da informacao. Mesmo com as melhores tecnologias de defesa, um usuario desprevenido pode comprometer toda a segurança de uma organizacao.

---

## 1. Por que a Conscientização é Importante?

### 1.1 O Fator Humano

- **90% dos ataques** começam com engenharia social
- **Erro humano** é responsável pela maioria dos incidentes
- **Usuários são o elo mais fraco** da cadeia de segurança
- **Investimento em conscientização** tem alto retorno

### 1.2 Estatísticas Alarmantes

- 1 em cada 3 breaches envolve phishing
- Custo médio de um breach: US$ 4,45 milhoes (IBM 2023)
- Tempo médio para identificar um breach: 277 dias
- 80% dos breaches envolvem credenciais roubadas

## 2. Principais Ameaças ao Usuário

### 2.1 Phishing

**O que é?**
Tentativa de obter informacoes sensiveis (senhas, dados bancarios) se passando por entidade confiavel via email, SMS ou sites falsos.

**Como identificar:**
- Endereço de email remetente suspeito
- Links que não correspondem ao dominio oficial
- Urgencia ou ameacas na mensagem
- Erros de portugues ou formatação estranha
- Anexos inesperados

**Exemplo de phishing:**
```
De: suporte@banco-seguro.com (dominio falso)
Assunto: URGENTE! Sua conta sera bloqueada!

Prezado cliente,

Detectamos atividade suspeita em sua conta.
Clique aqui para verificar: [link falso]

Se nao verificar em 24 horas, sua conta sera bloqueada.
```

**Como se proteger:**
1. Verifique o endereco do remetente cuidadosamente
2. Nao clique em links suspeitos
3. Acesse o site diretamente pelo navegador
4. Entre em contato com a instituicao por canais oficiais
5. Use autenticacao de dois fatores (2FA)

### 2.2 Senhas Fracas

**Problemas comuns:**
- Senhas curtas ou simples (123456, password)
- Reutilizacao de senhas em varios servicos
- Senhas previsiveis (nome, data de nascimento)
- Compartilhamento de senhas

**Regras para senhas fortes:**
1. Minimo de 12 caracteres
2. Mistura de maiusculas, minusculas, numeros e simbolos
3. Unica para cada servico
4. Nao usar informacoes pessoais
5. Trocar periodicamente (a cada 90 dias)

**Gerenciadores de senha:**
- Bitwarden (gratuito e open source)
- KeePass (local, gratuito)
- 1Password (pago)
- LastPass (freemium)

### 2.3 Engenharia Social

**Tecnicas comuns:**
- **Pretexting**: Criar situacao falsa para obter informacao
- **Baiting**: Deixar "isca" (pen drive infectado)
- **Tailgating**: Seguir pessoa em area restrita
- **Vishing**: Phishing por telefone
- **Smishing**: Phishing por SMS

**Como se proteger:**
1. Sempre verificar identidade da pessoa
2. Nunca fornecer informacoes sensiveis por telefone
3. Seguir politicas de segurança rigorosas
4. Reportar tentativas suspeitas

### 2.4 Malware

**Tipos comuns:**
- **Virus**: Se reproduz infectando outros arquivos
- **Worm**: Se espalha automaticamente pela rede
- **Trojan**: Se disfarça de software legitimo
- **Ransomware**: Criptografa dados e cobra resgate
- **Spyware**: Coleta informacoes sem consentimento
- **Keylogger**: Captura teclas pressionadas

**Como se proteger:**
1. Manter antivirius atualizado
2. Nao baixar software de fontes nao confiaveis
3. Nao clicar em links ou anexos suspeitos
4. Manter sistema operacional atualizado
5. Usar firewall e outras camadas de seguranca

### 2.5 Wi-Fi Publico

**Riscos:**
- Interceptacao de dados (Man-in-the-Middle)
- Pontos de acesso falsos (Evil Twin)
- Snoopring (captura de pacotes)

**Como se proteger:**
1. Evitar redes publicas para dados sensiveis
2. Usar VPN em redes publicas
3. Verificar se o HTTPS esta ativo
4. Desativar conexao automatica
5. Usar dados moveis quando possivel

## 3. Boas Práticas para o Usuário

### 3.1 No Ambiente de Trabalho

1. **Travar o computador** ao sair (Win+L)
2. **Nao deixar dispositivos** desacompanhados
3. **Reportar** atividades suspeitas imediatamente
4. **Seguir politicas** de segurança da empresa
5. **Usar apenas software** autorizado

### 3.2 No Ambiente Pessoal

1. **Atualizar** sempre o sistema e aplicativos
2. **Usar antivirius** em todos os dispositivos
3. **Fazer backup** dos dados importantes
4. **Cuidado** com o que compartilha nas redes sociais
5. **Verificar permissoes** de aplicativos

### 3.3 Em Dispositivos Moveis

1. **Usar bloqueio** de tela (PIN, biometria)
2. **Nao instalar** aplicativos de fontes nao oficiais
3. **Manter atualizado** o sistema operacional
4. **Cuidado** com links recebidos por mensagem
5. **Usar Find My Device** para rastrear se roubado

## 4. Programa de Conscientização

### 4.1 Estrutura de um Programa

1. **Diagnostico**: Avaliar nivel atual de conscientizacao
2. **Planejamento**: Definir objetivos e estrategia
3. **Execucao**: Treinamentos, simulados, comunicacoes
4. **Medicao**: Analisar resultados e impacto
5. **Melhoria Continua**: Ajustar com base nos resultados

### 4.2 Atividades Recomendadas

- **Treinamentos regulares**: Mensais ou trimestrais
- **Simulados de phishing**: Testar resistencia dos usuarios
- **Campanhas de comunicacao**: Emails, cartazes, videos
- **Workshops praticos**: Demonstracoes ao vivo
- **Gamificacao**: Competicoes e recompensas

### 4.3 Indicadores de Sucesso

- Reducao na taxa de cliques em phishing
- Aumento na reporte de tentativas
- Reducao em incidentes de seguranca
- Melhoria nos testes de conscientizacao
- Feedback positivo dos usuarios

## 6. Casos Reais

### 6.1 Ataque Sony Pictures (2014)

- **Ameaca**: Malware destructivo (wiper)
- ** vetor**: Email de phishing
- **Impacto**: Perda de dados, vazamento de informacoes
- **Licao**: Importancia de backups e segregacao de rede

### 6.2 WannaCry (2017)

- **Ameaca**: Ransomware global
- ** vetor**: Vulnerabilidade SMB (EternalBlue)
- **Impacto**: 200.000+ computadores em 150 paises
- **Licao**: Importancia de atualizacoes de seguranca

### 6.3 SolarWinds (2020)

- **Ameaca**: Supply chain attack
- ** vetor**: Atualizacao maliciosa de software
- **Impacto**: Comprometimento de agencias governamentais
- **Licao**: Importancia de verificacao de atualizacoes

---

## 7. Checklist do Usuario Seguro

- [ ] Senhas fortes e unicas para cada servico
- [ ] Autenticacao de dois fatores (2FA) ativada
- [ ] Antivirius atualizado e ativo
- [ ] Sistema operacional sempre atualizado
- [ ] Backup regular dos dados importantes
- [ ] Cuidado com emails e links suspeitos
- [ ] Computador trancado ao sair
- [ ] Redes publicas evitadas para dados sensiveis
- [ ] Software apenas de fontes oficiais
- [ ] Incidentes reportados imediatamente
